# Ansattliste — ITKO-rapportering

Én linje per ansatt, alle ansatte, også admin og ledelse. Ingen navn på personer eller kunder.

## Format per linje

```
rolle, teknologi, alder, oppdrag <%>, sektor, bransje.
```

Tillegg kun ved avvik fra default:

- `stilling <%>` — når stilling ≠ 100
- `admin <%>` — når admin ≠ 0
- `ledig fra <d.m>` — når oppdraget har kjent sluttdato
- `permisjon` — erstatter oppdrag-feltet ved permisjon
